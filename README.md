# IQ 300 แหกโรงบาล บน GitHub Pages + Supabase

ไฟล์ในชุดนี้
- `index.html` คือตัวเกมทั้งหมด (ไฟล์เดียว) แทนที่ไฟล์เดิมใน repo ของคุณได้เลย
- `setup.sql` คือคำสั่งสร้างตารางลีดเดอร์บอร์ดใน Supabase
- `README.md` คือไฟล์นี้

ถ้าไม่ตั้งค่า Supabase เกมยังเล่นคนเดียวได้ปกติ และห้องเล่นกับเพื่อน (ห้อง 101-105) ก็ใช้ได้ เพราะต่อกันตรงระหว่างมือถือ ไม่ผ่านเซิร์ฟเวอร์ของเรา มีแค่ลีดเดอร์บอร์ดรวมที่ต้องใช้ Supabase

## ขั้นตอน (ใช้เวลาประมาณ 10 นาที)

1. เข้า https://supabase.com สมัครบัญชีฟรี แล้วกด New project ตั้งชื่ออะไรก็ได้ รอจนโปรเจกต์พร้อมใช้
2. ไปที่เมนู SQL Editor กด New query วางข้อความทั้งหมดจาก `setup.sql` แล้วกด Run (รันซ้ำได้ ไม่พัง)
3. ไปที่ Authentication แล้วหาหน้า Sign In / Providers เปิดสวิตช์ **Anonymous sign-ins** (ชื่อเมนูอาจต่างเล็กน้อยตามเวอร์ชันของเว็บ) ผู้เล่นไม่ต้องสมัครสมาชิก ระบบสร้างตัวตนแบบไม่ระบุชื่อให้เอง
4. ไปที่ Project Settings แล้วหาหน้า API ก๊อปสองค่า คือ **Project URL** และ **anon public key** (คีย์ยาวขึ้นต้นด้วย `eyJ`) ห้ามใช้ `service_role` เด็ดขาด
5. เปิด `index.html` ด้วยตัวแก้ไขข้อความ หาบล็อก `SUPABASE_CONFIG` ใกล้ต้นไฟล์ แล้วแทนค่าสองบรรทัด

   ```js
   window.SUPABASE_CONFIG={
     url:'https://xxxxxxxx.supabase.co',
     anonKey:'eyJ...'
   };
   ```
6. อัปโหลด `index.html` ขึ้น repo GitHub (ทับไฟล์เดิม) รอ GitHub Pages อัปเดตสักครู่ แล้วกด Ctrl+F5 หรือรีเฟรชแรงๆ

## ทดสอบว่าใช้ได้

- หน้าแรกใต้ช่องชื่อควรขึ้นว่า "ออนไลน์: ผลของคุณขึ้นลีดเดอร์บอร์ดได้"
- ตั้งชื่อ หนีให้สำเร็จหนึ่งรอบ แล้วเปิดลีดเดอร์บอร์ด ชื่อคุณควรขึ้น
- ห้องเล่นกับเพื่อน ให้เปิดเว็บบนมือถือสองเครื่อง กดปุ่ม เล่น แล้วเข้าห้องเดียวกัน (เช่น ห้อง 101) คนแรกที่เข้าจะเป็นเจ้าของห้องโดยอัตโนมัติ ทั้งสองต้องเปิดหน้าเว็บนี้ค้างไว้

ถ้าขึ้นว่า "ออนไลน์: แข่งกับเพื่อนได้ แต่ผลยังขึ้นลีดเดอร์บอร์ดไม่ได้" แปลว่าเปิด Anonymous sign-ins ไม่สำเร็จ ให้กลับไปทำข้อ 3 (ห้องเล่นกับเพื่อนยังใช้ได้ตามปกติ)

## ข้อควรรู้

- ลีดเดอร์บอร์ดไว้เล่นกับเพื่อน ผู้เล่นแต่ละคนแก้แถวของตัวเองได้ จึงโกงเวลาได้ถ้าตั้งใจเปิดเครื่องมือนักพัฒนา ถ้าอยากกันโกงต้องมีเซิร์ฟเวอร์ตรวจเวลา ซึ่งชุดนี้ไม่มี
- ตัวตนผู้เล่นผูกกับเบราว์เซอร์ ถ้าล้างข้อมูลเว็บหรือเปลี่ยนเครื่อง จะเป็นผู้เล่นคนใหม่ (ชื่อเดิมกับสถิติเดิมยังอยู่ในแถวเก่า)
- โปรเจกต์ Supabase ฟรีจะถูกพักถ้าไม่มีการใช้งานนานราวหนึ่งสัปดาห์ ถ้าเกมเชื่อมต่อไม่ได้ให้เข้า Dashboard กด Restore
- ห้อง 101-105 ใช้ PeerJS (WebRTC) ผ่านตัวกลางสาธารณะเฉพาะตอนจับคู่ครั้งแรก แล้วข้อมูลตำแหน่งตัวละครกับแชตวิ่งตรงระหว่างมือถือ เจ้าของห้องเป็นศูนย์กลาง ถ้าเจ้าของห้องหลุด คนที่เหลือจะต่อห้องใหม่ให้เอง เครือข่ายบางแบบ (เช่น เน็ตมือถือบางเจ้า) อาจต่อกันไม่ติด
- ห้อง 101-105 เปิดให้คนแปลกหน้าเข้าได้ แชตถูกกรองคำหยาบ ลิงก์ และเบอร์โทรแบบพื้นฐาน ปิดแชตหรือปิดเสียงรายคนได้ แต่ตัวกรองกันได้ไม่ครบทุกกรณี ถ้าเด็กเล่นควรดูแลอยู่ใกล้ๆ
- เพลงประกอบมี 6 ธีม (ห้องโถง แอบย่อง คลั่ง บอส แข่ง ก๋วยเตี๋ยว) สังเคราะห์สดในเบราว์เซอร์ด้วย WebAudio ไม่มีไฟล์เสียงให้โหลด เริ่มเล่นหลังแตะหน้าจอครั้งแรก ปิดได้ด้วยปุ่ม "เพลง: เปิด/ปิด" ข้างปุ่มเสียง
- ค่า anon key เป็นค่าสาธารณะ ใส่ในหน้าเว็บได้ ความปลอดภัยของข้อมูลอยู่ที่กฎ RLS ใน `setup.sql`
